Stab

Sistema de Gestión de Inventario

Stab es un ecosistema avanzado de gestión de inventarios para Inversiones Cleer David C.A. Integra un modelo matemático estacional y categorización ABC para optimizar flujos de abastecimiento.

Versión 2.2.0
Estructura Progressive Web App (PWA)
Base de datos PostgreSQL (Supabase)
Autenticación Supabase Auth + Google OAuth
Estado ✓ Inventario por usuario (RLS)
